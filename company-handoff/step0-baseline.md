# Step 0 — baseline測定（会社Claude Codeに貼る1枚目）

> **これを最初に貼る理由**: 改善見込みの試算で一番弱い前提は「無駄な往復がどれくらいあるか」。
> Claude Code は会話ログを自動保存しているので、**過去に遡って現状の数字が取れる**。
> 待ち時間ゼロで、推測を事実に変えられる。

```
このセッションでは「測定」だけを行う。コードの修正・機能追加・リファクタリングは一切しない。

## 絶対制約
- 書き込みを許可するファイルは、以下の2つだけ。それ以外への Write/Edit は禁止。
  1. docs/ai-context/measure.py
  2. docs/ai-context/baseline-<今日の日付YYYY-MM-DD>.md
- ネットワークアクセスは禁止（この環境では通らない。試すな）。
- git commit / push はしない。ファイルを置くだけにする。
- 確認できなかったことは「未確認」と書く。推測で数字を埋めるな。

## やること

### 1. ログの所在を確認する
Claude Code は会話ログを ~/.claude/projects/<エンコードされたプロジェクトパス>/*.jsonl に保存する。
- そのディレクトリが存在するか確認する
- このプロジェクトに対応するサブディレクトリを特定する（パスの / が - に置換された形が多い）
- JSONLファイルが何本あり、最古と最新がいつか報告する
- **存在しなければ、ここで止まって報告する。** 以降の手順は実行しない。

### 2. スキーマを自分で確認する
ログの形式は Claude Code のバージョンや配信形態で変わる。決め打ちするな。
- JSONLファイル1本の先頭5行と末尾5行を読む
- 実際に存在するフィールド名を確認する。特に以下:
  - メッセージの役割を示すフィールド（role / type など）
  - タイムスタンプ
  - トークン使用量（usage.input_tokens / output_tokens / cache_read_input_tokens など）
- **usage が存在しない、または常に空の場合は、その事実を報告する。**
  社内ゲートウェイ経由だと入らない可能性がある。無ければトークン指標は諦めて、
  往復回数と所要時間だけで進める。無いものをあるように扱うな。

### 3. 集計スクリプトを書く
docs/ai-context/measure.py に、Python3の標準ライブラリのみで書く。
（docs/ 配下に置くのは、CIやlintに拾われてビルドを壊さないため）

引数で対象期間を受け取り、セッション（JSONL 1本 = 1セッション）ごとに集計する:
- ユーザー発言数（role が user のメッセージ件数。ツール結果やシステム由来のものは除外する。
  除外の判定基準は、手順2で確認した実際のスキーマに基づいて決め、スクリプト内にコメントで残す）
- 累計トークン（usage が取れる場合のみ）
- 所要時間（最初と最後のtimestampの差）

出力は、セッション一覧と、合計・中央値・平均。
**平均だけでなく中央値も出すこと。** 極端に長い1セッションに引きずられる。

### 4. 直近14日を集計して結果を書く
docs/ai-context/baseline-<今日の日付>.md に以下を書く:
- 測定日、対象期間、対象セッション数
- 1セッションあたりのユーザー発言数（中央値／平均／最大）
- 1セッションあたりのトークン（取れた場合のみ）
- 1セッションあたりの所要時間（中央値／平均）
- **取得できなかった指標は「取得不可」と、その理由**
- 再現手順（measure.py の実行コマンド1行）

### 5. 報告
上記の数字を画面にも出す。加えて、次の1点だけ所感を述べよ:
「ユーザー発言数の中央値」を見て、1タスクを終えるのに何往復かかっている水準か。

余計な提案・改善案の列挙はしない。数字と事実だけ返せ。
```

## あなたが見るゲート

| 見るもの | 判断 |
|---|---|
| ログが存在したか | 無ければ測定は諦める。Phase 0 へ進んでよい（測定なしで走らせる） |
| `usage` が取れたか | 取れなければトークン指標は以後すべて落とす |
| ユーザー発言数の中央値 | **これが後で比較する主指標。** 数字を覚えておく |

この数字が、Phase 1〜3を入れた後の「効いたのか」の唯一の判定材料になります。
1〜2週間運用してから `measure.py` を再実行して比較してください。
