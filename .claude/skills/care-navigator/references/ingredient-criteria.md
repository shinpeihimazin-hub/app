# 商品の「選ぶ基準」辞書（成分・剤形・選定基準）

このファイルは提案（S5）で読む。目的は**「これを買え」ではなく「どういう基準で選べばよいか」を渡すこと**。効果はすべて「一般に〜とされる」の枠で、確度・個人差・注意を添える。断定・捏造数値をしない。特定商品名はユーザーが求めたときに"基準に合う一例"として少数だけ挙げ、必要なら WebSearch で最新の商品例を一般語で探す（効能の裏取りには使わない）。

## 成分の当て方（悩み → 一般に選ばれる成分の方向性）

### 保湿・バリア（乾燥・ガサガサ・つっぱり）
- **セラミド**：角層の細胞間脂質の主成分。一般にバリア機能を補い水分を保つ目的で選ばれる。「ヒト型（表示例：セラミドNP/NG/AP等）」は親和性が高いとされる。乾燥・敏感肌でまず候補。
- **ヒアルロン酸・グリセリン・BG**：水分を抱える保湿成分。みずみずしい使用感。単体だと蒸散を防ぎにくいので、油分やセラミドと組み合わせる。
- **ワセリン・スクワラン・シアバター等の油性成分**：水分の蒸発を防ぐフタの役割。乾燥が強い・粉ふきに。ワセリンは低刺激で定番。
- 選ぶ基準：乾燥が軽い→化粧水+乳液、強い→クリームや油分を足す。**「入っているか」だけでなく剤形と使う順で決まる**。

### 抗炎症・鎮静（赤み・敏感・ゆらぎ）
- **グリチルリチン酸2K（甘草由来）**：一般に肌荒れ・炎症を抑える目的で医薬部外品に配合される定番。
- **ナイアシンアミド**：保湿・肌荒れ防止・皮脂やトーンなど多目的で使われる成分。比較的取り入れやすいとされる。
- 敏感時の選ぶ基準：**無香料・アルコール（エタノール）少なめ・低刺激設計**を優先。新規成分の重ねすぎを避け、シンプルに。

### 皮脂・角質・毛穴・ニキビ
- **サリチル酸（BHA）／AHA（グリコール酸等）**：角質・毛穴ケアで使われる。刺激・乾燥を招くことがあり、使いすぎ注意・保湿併用・UV対策とセット。
- **アゼライン酸・過酸化ベンゾイル・アダパレン等**：ニキビで用いられるが、日本では医療用/処方が中心のものもある。**炎症の強いニキビは市販で粘らず皮膚科**（跡を残さないため）。
- ニキビの選ぶ基準：**「ノンコメドジェニックテスト済」表示・油分控えめ・保湿は継続**。洗いすぎない。

### トーン・しみ・くすみ（美白目的）
- **ビタミンC誘導体／トラネキサム酸／ナイアシンアミド**：一般に美白（メラニン生成の抑制など）目的で医薬部外品に使われる代表成分。効果は穏やかで継続が前提、個人差あり。
- 選ぶ基準：**毎日のUV対策（日焼け止め）が土台**。攻めの成分より先に日焼け対策と保湿。急に変化するしみは受診。

### 髪・頭皮
- **髪のダメージ**：加水分解ケラチン/シルク等の"補修"を謳う成分、油分（アルガン等）で手触りを補う。熱・摩擦の低減が土台。
- **頭皮の乾燥/かゆみ**：アミノ酸系などマイルドな洗浄、すすぎと乾燥の徹底。脂性フケ・強い赤みが続くなら受診。

## 剤形（テクスチャー）の選び方
悩みは"成分"だけでなく"剤形"で決まることが多い。
- **化粧水**：水分中心。単体では乾燥をカバーしきれない。ベタつきが苦手な人・軽い乾燥に。
- **乳液・美容液**：水分＋適度な油分。バランス型。
- **クリーム**：油分多め。乾燥が強い・冬・粉ふきに。Tゾーンは薄く、など部位で量を調整。
- **オイル・ワセリン**：フタ。最後に少量。
- 一般的な順番：**さっぱり→こってり（水分の多いもの→油分の多いもの）**。

## 選定チェックリスト（提案時に必ず添える注意）
- [ ] **パッチテスト**：新しい製品は腕の内側などで試してから顔・広範囲へ。
- [ ] **一度に変えすぎない**：合わなかった時に原因を特定できるよう、1つずつ導入。
- [ ] **刺激成分の併用注意**：AHA/BHA・レチノール・高濃度ビタミンC等を同時多用しない。乾燥/刺激が出たら減らす。
- [ ] **UV対策は土台**：トーン・エイジング・敏感いずれでも日焼け対策が効く。
- [ ] **医薬部外品/化粧品/医薬品の別**：「〇〇を防ぐ」等の表現は医薬部外品の範囲。治療は医薬品・受診。
- [ ] **妊娠・授乳中／持病・服薬中／子ども**：市販薬・特定成分の可否は自己判断せず薬剤師・医師へ。
- [ ] 効果は個人差があり、断定はしない。合わなければ中止して様子を見る／受診。

## 商品名を出すときの作法（求められたら）
1. まず上の「選ぶ基準」を提示し、その基準に**合致する例**として少数挙げる。
2. WebSearch を使う場合のクエリは**成分名・カテゴリ名など一般語**（例：「セラミド クリーム 敏感肌」）。悩みの個人的詳細は入れない。
3. ランキング/アフィリエイト記事は**商品名の把握**に使い、効能の根拠にはしない。「この記事が1位と言っていた」を根拠にしない。
4. 「これを買うべき」ではなく「この基準に合う一例。最終的には成分表と自分の肌で確かめて」と枠づける。
5. 価格比較・最安値が必要なら price-hunter スキルの領域だと案内する（ここでは扱わない）。
