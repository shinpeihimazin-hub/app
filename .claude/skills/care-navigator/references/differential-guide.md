# 鑑別ガイド（症状 → 原因候補 → 確認する質問）

このファイルは問診（S2）の起点。**原因を先に決めつけないための「聞くべきこと」の地図**。ここに載る原因は「よくある候補」であって診断名ではない。断定せず、確認質問でユーザー自身の心当たりと突き合わせる。迷ったら red-flags.md を優先。

使い方：ユーザーの悩みから該当カテゴリを開く → 「まず確認する質問」を選択式/自由記述に振り分けて聞く → 回答で「原因候補」を絞る → 「見分けのヒント」で確度を上げる。

---

## 肌：乾燥・ガサガサ・粉ふき・つっぱり

**よくある原因候補（決めつけない）**
- 外的：空気の乾燥（冬・エアコン）、洗いすぎ・熱いお湯・ゴシゴシ摩擦、洗浄力の強い洗顔/ボディソープ、保湿不足やタイミングの遅れ
- 製品要因：合わない化粧品によるかぶれ（接触皮膚炎）、アルコールや香料などの刺激
- 肌質・体質：もともとの乾燥肌・敏感肌、加齢によるバリア機能低下、アトピー素因
- 内的・全身：睡眠不足・栄養の偏り、水分摂取、ホルモン変化、（広範・強いかゆみを伴うなら全身疾患の可能性→受診）

**まず確認する質問**
- （選択式）部位は？：顔全体／頬など一部／体（すね・腕）／手／全身
- （選択式）季節性は？：冬・乾燥期に悪化／一年中／最近急に
- （選択式）かゆみは？：ほぼ無い／軽い／強い（かき壊す）
- （自由記述）いつから？きっかけの心当たり（新しい化粧品・洗剤・環境変化）は？
- （自由記述）今の洗い方・頻度・使っている洗顔/保湿は？入浴の湯温は？

**見分けのヒント**
- 冬だけ・こすると悪化・保湿で軽快 → 乾燥/摩擦性の可能性が高い（生活とスキンケアの見直しが軸）
- 特定製品を使い始めてから・境界がはっきり赤い・かゆい → かぶれ（接触皮膚炎）を疑い、その製品を止めて様子見。改善しなければ受診
- 強いかゆみ・じくじく・全身・繰り返す → セルフケアの範囲を超える可能性。受診を促す

## 肌：ニキビ・吹き出物

**よくある原因候補**
- 皮脂過剰と毛穴詰まり（思春期・皮脂の多い部位）、ホルモンバランス（生理周期・思春期・ストレス）
- 誤ったケア：洗いすぎで乾燥→皮脂過剰、油分過多の製品、こすり、つぶし癖
- 生活：睡眠不足・食生活・寝具/マスクの摩擦
- 大人ニキビは乾燥・バリア低下が絡むことも

**まず確認する質問**
- （選択式）できる場所は？：Tゾーン中心／口周り・あご（フェイスライン）／背中・胸／広範
- （選択式）タイプは？：白/黒い詰まり中心／赤く腫れる・痛い／膿を持つ・しこり
- （選択式）周期性は？：生理前に増える／常時／不定
- （自由記述）今のスキンケア・使っている薬やコスメ・生活で心当たりは？

**見分けのヒント**
- あご・口周り・生理前 → ホルモン/大人ニキビ寄り（保湿しつつ皮脂と角質のケア）
- 赤く腫れて痛む・膿・しこり・広範・跡が残る → 炎症が強い。市販ケアで無理をせず皮膚科（跡・瘢痕を避けるため早めの受診が有利）

## 肌：赤み・かゆみ・ヒリつき（敏感・かぶれ）

**よくある原因候補**
- 接触皮膚炎（化粧品・金属・洗剤・植物）、刺激（アルコール/香料/AHA/BHA等の使いすぎ）、乾燥由来の敏感化
- 日焼け後、寒暖差、体質（アトピー・脂漏性など）

**まず確認する質問**
- （選択式）範囲は？：塗った所だけ／顔全体／体に広がる
- （選択式）経過は？：数時間〜数日で出た／じわじわ慢性
- （自由記述）直前に新しく使ったもの・触れたもの（コスメ・アクセ・洗剤・植物）は？

**見分けのヒント**
- 「使った所と一致」「新しい製品の直後」 → まず原因候補を中止（除去）。多くはこれで軽快
- 急な全身の発疹・腫れ・息苦しさ → アナフィラキシー疑い。**救急**（red-flags参照）

## 髪：パサつき・広がり・枝毛・切れ毛

**よくある原因候補**
- ダメージ：カラー/ブリーチ/パーマ、ドライヤー/アイロンの熱、紫外線、摩擦（タオル/枕）
- ケア要因：洗浄力の強いシャンプー、乾かさず自然乾燥、トリートメント不足
- 頭皮/体質：加齢・うねり毛、乾燥

**まず確認する質問**
- （選択式）主な悩みは？：手触りのパサつき／広がり・うねり／枝毛・切れ毛／艶がない
- （選択式）ダメージ源の心当たり：よくカラー/ブリーチ／熱スタイリング毎日／特になし
- （自由記述）今のシャンプー・乾かし方・タオルドライの仕方は？

**見分けのヒント**
- 施術毛先中心 → ダメージ性（補修・熱/摩擦の低減が軸）
- 頭皮のかゆみ/フケ/抜け毛increaseを伴う → 頭皮トラブル側も確認（下記）

## 頭皮：フケ・かゆみ・べたつき・におい

**よくある原因候補**
- 乾燥性フケ（細かい粉）／脂性フケ（大きく湿ったフケ、脂漏性の傾向）、洗いすぎ or 洗い残し、合わないシャンプー、すすぎ不足
- 皮膚炎（脂漏性皮膚炎など）を疑うケースは受診

**まず確認する質問**
- （選択式）フケのタイプ：細かく乾いた/大きく湿った/赤み・強いかゆみを伴う
- （自由記述）シャンプーの頻度・種類・すすぎ・乾かし方は？

**見分けのヒント**
- 赤み・強いかゆみ・大きく湿ったフケが続く → 脂漏性皮膚炎などの可能性。市販で改善しなければ受診

## 肌：くすみ・色ムラ・しみ（見た目トーン）

**よくある原因候補**
- 乾燥/角質肥厚によるくすみ、血行、紫外線由来の色素沈着、こすりによる摩擦黒ずみ、生活（睡眠・喫煙）
- しみは種類が多く自己判断が難しい。急に変化する色素斑は受診（red-flags：ホクロの変化）

**まず確認する質問**
- （選択式）気になるのは：全体のくすみ・トーン／部分的なしみ・そばかす／こすれる所の黒ずみ
- （自由記述）日焼け対策の習慣・こすり癖・気になり始めた時期は？

**見分けのヒント**
- 全体のくすみ → 保湿・角質ケア・UV対策・生活が軸
- 境界のはっきりしたしみ・急な変化 → 種類の見極めが要る。皮膚科相談を促す

## 体調・全身系（美容周辺）

肌・髪は全身状態の鏡でもある。次のような相談は、生活改善の一般論は示しつつ、**セルフケアで扱える範囲か**を見極め、範囲を超えるものは受診を促す：
- 「疲れが取れない」「むくむ」「冷える」「便秘」など → 生活（睡眠・水分・食事・運動・入浴）の一般的な整え方は示せる。ただし持続・悪化・痛みを伴うものは受診。
- サプリ/健康食品を求められたら：一般的な栄養の話に留め、**治療目的の断定をしない**。持病・服薬中・妊娠授乳中は医師/薬剤師に確認を促す。

**原則**：全身症状・持続する不調・痛みを伴うものは、このスキルの範囲を超える。無理に商品へ誘導せず受診を促す。
