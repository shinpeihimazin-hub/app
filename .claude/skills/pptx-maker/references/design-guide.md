# S6 ビジュアル品質ガイド（視覚レビューの観点）

前提：**ビジュアルの土台は会社テンプレのスライドマスター**。このガイドはテンプレ規定と競合したら**常にテンプレが勝つ**。

## PDFを目視するときのチェックリスト（S6で毎周実施）

### 機械警告の確認（qa_report.json）
- [ ] 文字あふれ警告が0件（あれば本文を短くする/ノートへ逃がす。フォントを勝手に縮めない）
- [ ] 空のプレースホルダ警告が意図通りか（意図せぬ空枠は削除かレイアウト変更）

### 視覚確認（PDF全ページ）
- [ ] **見出しだけ追って話が通るか**（流れの最終確認）
- [ ] 1スライドの視線の起点が1つか（要素が多すぎて目が迷子にならないか）
- [ ] 箇条書きの行数・字数がスライド間で極端に凸凹していないか
- [ ] 図表：軸ラベル・単位・出典があるか。凡例がはみ出ていないか。**dataviz の配色指針とテンプレ配色の整合**
- [ ] 画像のアスペクト比が歪んでいないか
- [ ] 表紙・中扉・本文でレイアウト種別を正しく使い分けているか
- [ ] 「要確認」マークの残存箇所を最終報告に列挙したか

## 修正の優先順位
1. 事実の誤り・「要確認」の無断消滅（即修正）
2. 文字あふれ・レイアウト崩れ（機械警告）
3. 流れの破綻（見出しリレーの断絶）
4. 美観（余白・整列・色数）

## やってはいけないこと
- テンプレのマスターを書き換える（配布物の同一性が壊れる）
- 色数を増やして解決しようとする（テンプレ配色＋強調1色まで）
- 文字サイズの手動縮小での押し込み（読めない資料は品質ゼロ。削る勇気）
