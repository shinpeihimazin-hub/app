# 記憶スキーマ（study-memory/）

1項目 = 1ファイル。`study-memory/<YYYYMMDD>-<ascii-slug>.md`。
索引ファイルは作らない（本体とズレて必ず腐る）。一覧が要るときは `grep` でfrontmatterを舐める。

## ファイル名
- `20260728-deadlock-conditions.md` のように **日付8桁 + ASCIIのslug**。
- 日本語ファイル名にしない（シェルで扱いにくい）。slugは英小文字・数字・ハイフンのみ。
- 同名が既にあれば末尾に `-2` を付ける。

## frontmatter（全項目 必須。空でもキーは残す）

```yaml
---
id: 20260728-deadlock-conditions
topic: テクノロジ/OS
tripped_on: 「循環待ち」と「相互排除」の区別がつかない
added: 2026-07-28
last_asked: ""
recent: ""
formats_used: []
source: 過去問道場 令和5年春 問18
---
```

| キー | 意味 | 規則 |
|---|---|---|
| `id` | ファイル名のstemと同じ | 変えない |
| `topic` | 分野 | `テクノロジ/…` `マネジメント/…` `ストラテジ/…` の2階層。範囲指定出題（「今日はネットワークから」）はここで絞る |
| `tripped_on` | **急所**。本人がどこで詰まったか | 1行。「◯◯が分からない」ではなく「◯◯と△△の区別がつかない」「計算の第2手順で止まる」まで具体化する。**出題はここを狙う** |
| `added` | 追加日 | `YYYY-MM-DD` |
| `last_asked` | 最後に出題した日 | 未出題は `""` |
| `recent` | 直近の正誤 | `o`=正解 `x`=誤答 のASCII文字列。**新しいものを右に追記**。最大5文字（6件目からは左を捨てる）。例: `xoo` = 3回出して直近2回正解 |
| `formats_used` | 出題に使った形式 | `mcq` / `cloze` / `calc` / `explain`。**新しいものを右に追記**。次の形式選択に使う |
| `source` | 出典 | 過去問道場の年度・問番号、URL、「仕事で遭遇」など。無ければ `""` |

## 本文の構成（見出しは固定）

```markdown
## 何が分からなかったか
（本人の言葉をそのまま。要約して綺麗にしない。綺麗にすると急所が消える）

## 解説
（具体例を最低1つ含む。事実と推測を分ける。未確認は「未確認」と書く）

## 一行でいうと
（本人が言い直した言葉を優先して採用する。無ければこちらで1行）

## 本番での問われ方
（FEでどう出るか。計算問題なら典型的な数値の置き方）
```

## 更新手順

**追加時**（記憶モード）
1. `ls study-memory/ | grep <slug>` で重複を確認（同じ論点を二重登録しない。既にあれば追記で育てる）
2. Writeで新規作成。`last_asked: ""` `recent: ""` `formats_used: []`

**出題後**（出題モード）— Editで3つだけ書き換える
1. `last_asked` を今日の日付に
2. `recent` に `o` か `x` を右から追記（5文字を超えたら左を1文字捨てる）
3. `formats_used` に使った形式を右から追記

誤答だった場合、**本文の「解説」に何を取り違えたかを1〜2行 追記してよい**。これは知識のメモであって成績ではない。

## 禁止（違反したらこのスキルは本人にとって害になる）

- **正答率・連続日数・累計問題数・「◯日ぶり」を、計算も表示もしない。** `recent` と `last_asked` は出題順を決める内部状態であって、本人に見せる数字ではない。
- 「前も同じところで間違えてる」と本人に言わない。誤答時に言うのは「そこはまだ穴。また出す」まで。
- frontmatterに `score` `streak` `correct_count` `accuracy` の類のキーを増やさない。作った瞬間に見せたくなる。
