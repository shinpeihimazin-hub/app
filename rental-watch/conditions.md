## 「家賃17万」の扱い — **管理費・共益費込み**で確定（2026-07-29 本人確定）

`RENT_CAP_INCLUSIVE = True`。**賃料 + 管理費・共益費 の合計が17万円以下**のものだけを通す。

各サイトへのクエリは賃料（管理費抜き）17万円以下で投げている。
管理費は必ず0以上なので「賃料 ≤ 17万」は「込み ≤ 17万」の上位集合になり、**取りこぼしは出ない**。
込みで超過するものは取得後にこちら側で落とす。

この確定により **Ｃ－Ｆｌａｔ 201（賃料16.7万＋管理費0.7万＝込17.4万）は対象外**になった。

## 初期費用40万の帰結 — 敷礼ゼロが事実上の必須条件

仲介0.55ヶ月・保証会社50%・諸費用4万で上限40万を解くと:

```
敷礼ゼロ       → 賃料 17.5万まで可
敷礼 計0.5ヶ月 → 賃料 14.1万まで
敷礼 計1ヶ月   → 賃料 11.8万まで   ← 想定レンジの外
```

込み17万で40万に収めるには**敷礼がほぼゼロでないと数学的に届かない**。

当初は SUUMO 側で `co=3`（礼金なし）を掛けて母数を落としていたが、
「敷金ゼロ＋礼金0.5ヶ月」は賃料14.1万まで通るため取りこぼす。撤去して全件走査に変えた。
実測では 85件中77件が初期費用で落ちる。ここが最も強い足切りになっている。

### LIFULL HOME'S を「未対応」としていたのは誤りだった（2026-07-31 訂正）

以前「ページは200で返るが物件データがサーバ側で描画されない」と記録していたが、
これは**駅スラッグを取り違えて404ページを掴んでいた**ための誤判定。
404ページはナビゲーションだけを含むので、`万円`の出現がナビ由来しか無く、
「物件が描画されていない」ように見えていた。
正しいスラッグ（例 `oimachi_00603`）ならHTMLに物件が全部入っている。

### HOME'S の実測パラメータ

- 駅URL: `https://www.homes.co.jp/chintai/tokyo/{slug}_{駅コード}-st/list/`
  スラッグは路線ページ（例 `/chintai/tokyo/yamanote-line/`）の
  `name="cond[roseneki][...]"` の隣の駅リンクから採れる
- `cond[monthmoneyroomh]=17`（**万円単位**）/ `cond[housearea]=40` / `cond[houseageh]=25`
  / `cond[walkminutesh]=15`
- `cond[housekouzougroup][rebar]=rebar` … 鉄筋系（RC/SRC）。**構造がサーバ側で効く唯一のサイト**
- `cond[mcf][220301]` バス・トイレ別 / `cond[mcf][223101]` 洗面所独立
  （実測：洗面所独立を外しても結果はほぼ変わらない＝絞りすぎではない）
- `cond[madori][15|22|23|25|32|33|35|42|43|45-]` … 1LDK以上
- ページングは `page=N`、**1ページ10件**。総件数は「総物件数：N件」から採る
- 0件の目印は `条件に一致する情報は見つかりませんでした`。
  **この目印が無いのに物件ブロックも無い場合はレート制限**なので、
  待って引き直す（0件として扱うと静かに監視が死ぬ）

## いい部屋ネット（大東建託パートナーズ）について

詳細条件が**URLに乗らない**。`detail.priceMax=...` 等を付けても
`serializedCondition` は全項目 null のまま返る（条件はクライアント側が保持している）。
一方で**物件データは `__NEXT_DATA__` の `buildingSearchResult.buildings` に全部入っている**ので、
区単位で全ページ取ってこちらで絞る形にするしかない。
連続アクセスで403（WAF）に入るが、1〜2分待てば復帰する。

### at home の駅スラッグ

`tamachi` / `takanawagateway` / `shinagawa` / `osaki` / `gotanda` / `meguro` / `oimachi` / `omori`
（`https://www.athome.co.jp/chintai/tokyo/{slug}-st/list/`。`ohmori` は404）

一覧に **住所・駅徒歩・築年月・設備（バス・トイレ別）** まで出るので情報量は3サイト中で最も濃い。
ただし **建物構造（RC/SRC）が一覧に無い** ため、RC判定だけは通知後に人が確認する。

## 自動判定できないもの（通知後に人が見る）

1. **各室の畳数**（リビング6畳・寝室4畳以上）— 両サイトにフィルタが無い
2. **二人入居可** — 不動産ジャパンは `rsdn[]=RSDN06` で絞れるが、
   付けると母数が激減するため取得段階では外し、詳細ページの記載を通知に載せる
3. ハトマーク側の構造（RC/SRC）— `mansion` 種別での近似
