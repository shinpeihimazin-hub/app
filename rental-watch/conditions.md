# 監視条件（確定版）

最終更新: 2026-07-28

## MUST（すべて満たすこと）

| 項目 | 値 |
|---|---|
| 間取り | 1LDK以上（1LDK / 2K / 2DK / 2LDK / 3K / 3DK / 3LDK / 4K / 4DK / 4LDK以上） |
| 構造 | 鉄筋コンクリート（RC）または鉄骨鉄筋コンクリート（SRC） |
| 築年数 | 25年以内 |
| 駅徒歩 | 15分以内 |
| 専有面積 | 40㎡以上 |
| 各室 | リビング6畳以上・寝室4畳以上 ※**自動判定不可**。通知後に間取り図で目視確認 |
| water回り | バス・トイレ別／洗面所独立（＝洗濯機置場がトイレと別の部屋）／室内洗濯機置場 |
| 家賃 | 17万円 |

### 対象駅（いずれかから徒歩15分以内）

田町 / 高輪ゲートウェイ / 品川 / 大崎 / 五反田 / 目黒 / 大井町 / 大森

## 「家賃17万」の扱い — 未確定のため広めに取る

込み／抜きがユーザー未回答のため、**賃料（管理費抜き）17万円以下で取得**し、
通知時に **管理費込みの金額を併記** する。込みで17万を超えるものには `[込み超過]` を付す。

→ ユーザーが「込み17万」と確定したら `watch.py` の `RENT_CAP_INCLUSIVE = True` にする。

## 監視対象サイト

SUUMO / LIFULL HOME'S / カナリー は**使わない**（ユーザーが自分で見ているため重複）。

| サイト | 運営 | 検索軸 | 備考 |
|---|---|---|---|
| 不動産ジャパン | 公益財団法人 不動産流通推進センター | 駅指定（8駅） | 築年は詳細ページから取得して絞る |
| ハトマークサイト | 全国宅地建物取引業協会連合会 | 区指定（品川・大田・目黒・港）→駅で絞る | `built_to=25` がサーバ側で効く |

## 検索パラメータの実測メモ

### 不動産ジャパン
- 駅コード: 田町`C8MR8BDBN` 高輪GW`C8MR8BD5N` 品川`C8MR8B5BD` 大崎`C8MR8BRBI`
  五反田`C8MR8BSB9` 目黒`C8MR8BXB4` 大井町`C8MX58RBI` 大森`C8MX58SB9`
- `toil[]=TOIL04` バス・トイレ別室 / `wsng[]=WSNG02` 室内洗濯機置場 / `wash[]=WASH13` 洗面所
- `wash[]=WASH03`（独立洗面脱衣所）は**賃貸では機能しない**（0件になる）ので使わない
- `exclusive_area_from=40` / `price_r_to=170000` / `eki_walk=15` / `limit=100`
- 築年フィルタ `built` は20年までしか無い → **詳細ページの「築年月」で判定する**
- 詳細URL: `https://www.fudousan.or.jp/property/detail?p_no={p_no}`

### ハトマークサイト
- 区コード: 品川`13109` 大田`13111` 目黒`13110` 港`13103`
- `bath[]=BATH01` バス・トイレ別 / `wash[]=WASH04` 洗面所独立
- `home_category[]=mansion` / `built_to=25` / `building_area_all_from=40` / `price_r_to=170000`
- `eki_walk=15` / `limit=100` / ページングは `page=N`

## 自動判定できないもの（通知後に人が見る）

1. **各室の畳数**（リビング6畳・寝室4畳以上）— 両サイトにフィルタが無い
2. **二人入居可** — 不動産ジャパンは `rsdn[]=RSDN06` で絞れるが、
   付けると母数が激減するため取得段階では外し、詳細ページの記載を通知に載せる
3. ハトマーク側の構造（RC/SRC）— `mansion` 種別での近似
